MOHAMMAD ROHAN — PORTFOLIO WEBSITE

Files
- index.html: complete single-file portfolio website.
- profile.jpg: optional portrait image you add yourself (not included yet).

HOW TO PREVIEW
1. Open index.html in a browser.
2. To preview a portrait locally, press “Customize portrait +” and choose a photo. This preview is only on that browser; it does not publish the photo.

HOW TO PUBLISH / UPDATE ON GITHUB PAGES (PHONE OR COMPUTER)
1. Open https://github.com/MorganiteGaming/Rohan
2. Open the repository's main/root folder.
3. Choose Add file → Upload files (on mobile, you may need the browser's desktop-site option).
4. Upload/replace index.html from this package, then commit the changes.
5. To make your portrait public on the website, put a copy of your chosen photo in the same root folder and name it exactly profile.jpg. Upload it and commit. Use a JPG/JPEG image if possible.
6. Open https://morganitegaming.github.io/Rohan/ and refresh after GitHub Pages finishes publishing. If the old version appears, wait a few minutes and refresh.
